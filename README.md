# ANIKET TRADERS Website Starter

Responsive React + Vite website starter with an interactive Three.js shop illustration, product enquiry links, WhatsApp and Google Maps links.

## Important status
This is a website starter, not a deployed/live website. Supabase is not connected yet; admin login, product management and MFA must be configured and tested before production use.

## Run on a computer
Install Node.js, extract this ZIP, open a terminal in the extracted folder, then run:

```sh
npm install
npm run dev
```

For production build: `npm run build`.
